# Cursor・Claude・Genspark 比較レポート：同じプロンプトで4つの題材を作らせてみた

## 1. 結論

- 3ツールとも4題材すべてで要件を満たし、手直し0回で完成しました。差が出たのは品質の合否ではなく「速さ」「確認の仕方」「前の成果物の引き継ぎ方」です。
- 速さは Claude（Claude Code）が全題材で最速で、4題材の合計は約6分半でした。Cursor は実機での動作確認に時間をかけ合計約52分、Genspark は合計約42分でした。
- Cursor は内蔵ブラウザを使った確認が最も徹底していました。Genspark は出典付きで情報量の多い成果物を作り、実行途中に利用者へ確認の質問をすることがあります。
- 前の題材で作ったキャラの名前は、Claude と Genspark が最後まで維持しました。Cursor は「ぽて柿」→「ポテガキ」と名前がぶれました。

## 2. 実験の目的とルール

- 目的: 同じプロンプトを3つの AI エージェントに渡し、成果物と作り方の違いを比べる（2026-10-30 実施）
- 一発目の出力を v1、手直し後を final として保存しました。手直しは最大2回までのルールでしたが、今回は全題材で手直し0回です。
- 評価は、客観指標（所要時間・手直し回数・そのまま動いたか・要件充足数）と、見た目の ◎○△（筆者の主観）の2本立てです。
- 題材は4つです。03 と 04 は、各ツールが 02 で自作したキャラを使います。
- プロンプトは「自然な一文＋最低限の要件」の形にそろえました（全文は付録）。
- 他ツールの成果物を参照しないよう、作業フォルダはツールごとに分離しました。

| 普段の設定 | ~/.claude/CLAUDE.md を読み込み | User Rules なし。ただし ~/AGENTS.md を読み込み | なし |

- Cursor のデフォルトモデルは Claude ではなく Grok でした。モデルは変えずに実験しています。
- Claude と Cursor は、筆者が普段使っている指示（検証を重視する内容）の影響を受けています。
- 画像の渡し方は、Claude と Cursor は作業フォルダに画像を置いてファイル名で指定し、Genspark は画像を添付しました。

## 5. 横断して見えた違い

| 観点 | Claude | Cursor | Genspark |
|---|---|---|---|
| 速さ | 全題材で最速（1〜3分） | 12〜23分（02 のみ約1分） | 2〜25分 |
| 自己検証 | 軽く確認して即修正 | ブラウザ操作を伴う徹底確認 | 途中で利用者に確認の質問 |
| 画像の作り方 | 画像生成を使わずコード（SVG）で描く | 画像生成 | 画像生成 |
| 文脈の引き継ぎ | 画像内の文字から名前を維持 | ファイル名から推測し、名前がぶれた | カード画像から名前・プロフィールを維持 |
| 返答の言語 | 01〜03 は最後の返答が英語、04 は日本語 | 日本語 | FIXME: Genspark の返答言語を確認する |

- 作り方: Claude はコードで完結させ、Cursor はスキルやライブラリを導入して手順どおりに作り、Genspark は Web 上のサービス内で画像生成やスライド機能を使いました。
- 自己検証の深さ: Cursor は確認を徹底する分、時間がかかります。Claude は確認が軽い分、速く終わります。どちらも今回は手直し不要でした。
- 確認の質問: 質問をしたのは Genspark だけで、02 で選択式の質問が出ました。利用者が気づかないと待ち時間が発生します。
- 文脈の引き継ぎ: 名前を画像の中に文字で入れた Claude と、カード画像を別に用意した Genspark は、後工程でも名前を維持できました。画像に文字がなかった Cursor は、ファイル名から名前を推測し、最後は表記が変わりました。後工程に引き継ぐ情報は、成果物そのものに残しておくのが確実です。

## 6. 実験中に起きたトラブルと対策

| トラブル | 対策・影響 |
|---|---|
| Cursor の LP 1回目が「前の題材」を探して上位フォルダを検索し、Claude の LP を全文読んでいた | 不採用にし、作業フォルダを他ツールと分離して取り直した |
| Cursor が確認用に立てたローカルサーバーが止まらずに残っていた（LP 1回目） | 筆者が手動で停止した |
| Claude の LP で筆者がプロンプトを貼り間違えた（2回） | やり直した。不採用分は比較に使っていない |
| Genspark の途中の質問に筆者が気づかず待ち時間が発生した（02） | 推奨の選択肢で回答した。所要時間の解釈に注意 |
| Genspark の LP にアクセス解析スクリプト（Cloudflare）が残っていた | 公開前に削除した |

## 8. 付録

### プロンプト全文（全ツール共通）

01 テトリス
> シンプルなテトリスを作ってください。
> - ブラウザで開くだけで遊べる単一の HTML ファイル（外部ライブラリなし）
> - 7種類のブロック、回転、ライン消去、スコア、ゲームオーバー
> - キーボードで操作

02 柿のゆるキャラ画像
> かわいい柿のゆるキャラの画像を作ってください。
> - ゆるキャラ風で、親しみやすい表情
> - キャラクターの名前と一言プロフィールもつけてください
> - 画像の形式は問いません（PNG / SVG など）

03 ゆるキャラ紹介 LP
> 前の題材で作った柿のゆるキャラ（画像を添付 / 指定）を紹介するランディングページを作ってください。

> - キャラクター紹介、プロフィール、柿の魅力を伝えるセクションを含める
> - スマートフォンでも崩れずに見られる

04 柿のスライド資料

> - 形式は問いません（HTML / PPTX / PDF など）
